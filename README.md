# NAS100USD · OANDA

One page with five live TradingView charts of OANDA's US Nas 100: 1 hour, 4 hours, daily, weekly
and monthly. Each chart shows EMA 50, 150 and 200 and labels the swing highs and lows.

View it at https://esmyllyaho90.github.io/nas100usd-oanda/

The page is a single `index.html` with no build step, served by GitHub Pages. Open the file in a
browser to see it locally.

The charts are TradingView's free embeds. They update live in the browser and the page does not
store or read any prices itself.
